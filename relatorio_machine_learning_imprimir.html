1. Qual é a Estrutura do Banco de Dados do Projeto EstudeMy?

🍃 Banco NoSQL MongoDB 7.0 (Base: estudemy)

O sistema armazena dados gamificados de estudo em 5 coleções principais:

  • users: _id, nome, username, email, personagem (Samurai, Mago, Guerreiro), xpTotal, idioma, tema.
  • trilhas: _id, titulo, materia (11 disciplinas), dificuldade (Fácil, Médio, Difícil), visualizacoes.
  • secoes & fases: cenario (Vila, Montanha, Deserto, Castelo), personagem_selecionado (Spectre 100HP, Arqueira 150HP, Mago Corrompido 200HP, Cavaleiro Decaído 250HP) e perguntas.
  • progresso & rankings: userId, trilhaId, faseId, pontuacao, acertos, erros, totalPerguntas, mediaAcertos.

🎯 2. No Projeto, o que é o X e o que é o Y?

  • Matriz X (Variáveis Independentes / Entrada): Vetor de 18 características consolidando perfil do jogador, engajamento nas trilhas e telemetria das batalhas/quizzes.
  • Vetor Y (Variável Alvo / Saída Supervisionada - classe_y): Classifica o nível de domínio pedagógico e risco do estudante em 3 classes:
    • 0: Basico_Risco_Evasao (330 alunos — precisa de reforço / Trilha Fácil)
    • 1: Intermediario_Regular (350 alunos — evolução constante / Trilha Média)
    • 2: Avancado_Mestre (320 alunos — alta performance / Trilha Difícil)
